# Privacy Statement

## EUAA Monitoring Anonymiser

### Data processing

This application processes documents **entirely within your browser**.

- **No files are uploaded** to any server.
- **No text content is transmitted** over the network.
- **No analytics, tracking, or telemetry** of any kind.
- **No cookies** are set.
- Session data (replacement maps, processed output) is held in browser memory only and is discarded when you close the tab or click "Clear session".

### External libraries loaded

The following JavaScript libraries are loaded from the jsDelivr CDN at page load time. They are read-only script files — no document content is sent to them:

| Library | Purpose |
|---|---|
| `pdfjs-dist` | PDF text extraction (Mozilla, open source) |
| `pdf-lib` | PDF editing / redaction (open source) |
| `mammoth` | DOCX → text extraction (open source) |
| `docx` | DOCX generation (open source) |
| `xlsx` | Excel file processing (open source) |
| `jszip` | ZIP bundling for downloads (open source) |
| `jspdf` | PDF generation (open source) |
| `tesseract.js` | OCR for scanned PDFs (runs locally in browser) |
| `font-awesome` | UI icons (CSS only) |

### Intended use

This tool is designed for **EUAA monitoring demonstration purposes** — preparing anonymised versions of case files where no real personal data should be traceable.

**Always review anonymised output before using it in any official context.**
